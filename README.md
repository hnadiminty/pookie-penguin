 Valentine Website ^_^

A playful, interactive Valentine’s Day website made with love, chaos, and effort (in the best way).

This project is a multi-step “Will you be my Valentine?” experience featuring:
- Cute photos
- Teasing questions
- Sound effects
- A runaway **NO** button 😈
- Confetti celebration on **YES** 🎉

(Built as a personal Valentine gift.)
